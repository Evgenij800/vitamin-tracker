# Умный трекер витаминов и здоровья

Веб-приложение для профилактики здоровья: трекер приёма витаминов, опрос самочувствия с генерацией отчёта, хранение PDF-анализов, напоминания о приёме.

## Функционал
- Регистрация и вход по email
- Онбординг из 3 экранов
- Трекер витаминов с отметкой приёма и историей
- Опрос из 5 вопросов с персональным отчётом и рекомендациями
- Загрузка, скачивание и удаление PDF-анализов
- Профиль: ФИО, пол, возраст, цели здоровья
- Журнал напоминаний и веб-уведомления
- Переходы на лендинги партнёрских продуктов

## Локальный запуск
pip install -r requirements.txt
python app.py
